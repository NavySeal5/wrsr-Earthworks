# Change log

## 0.16.64-release-candidate — 14 November 2026

- Moved Site centroid calculation into the core planning module.
- Kept detailed click-routing and table-wheel traces in Developer UI builds. The player build omits these diagnostic messages.
- Added a versioned package with source, license texts, compatibility notes, and known issues.

## 0.16.63-distance-based-facility-contribution

- Added optional distance-based facility contribution with editable Close, Medium, and Far thresholds.
- Set the candidate rate to 250 m³ per in-game day for each displayed vehicle Speed/Level point at 1×.
- Added the candidate release scope and player-run review checklist.

## Earlier development builds

Earlier builds added polygon Sites, per-point heights, Site editing, named Projects, facility assignment, terrain execution, persistence, and Small, Medium, and Large facilities. The [stage review log](docs/STAGE_REVIEWS.md) records their changes and acceptance status. It also lists checks that remain unverified.
